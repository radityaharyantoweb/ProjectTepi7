# ☕ KopiTepi7

KopiTepi7 adalah website coffee shop yang dibuat untuk menampilkan informasi dan produk dari kedai kopi dalam tampilan yang modern, sederhana, dan responsif.

## ✨ Fitur

- 🏠 Landing page coffee shop
- ☕ Daftar produk/menu
- 🖼️ Tampilan gambar produk
- 📱 Responsive design
- 🧭 Navigation bar
- 📋 Informasi coffee shop
- 📞 Contact section

## 🛠️ Teknologi

Project ini dibuat menggunakan:

- HTML5
- CSS3
- Bootstrap
- SASS / SCSS
- JavaScript

## 🎯 Tujuan

Project ini dibuat sebagai latihan dalam membangun website menggunakan HTML, CSS, Bootstrap, dan SASS serta menerapkan responsive web design.

## 📱 Responsive

Website dirancang agar dapat menyesuaikan tampilan pada berbagai ukuran layar, mulai dari desktop hingga perangkat mobile.
